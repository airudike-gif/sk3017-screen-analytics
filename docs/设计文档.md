# 全国新能源汽车充电基础设施运营态势大屏 · 设计文档

## 一、数据集来源与字段说明

| 项目 | 内容 |
| --- | --- |
| 数据集名称 | 全国充电站信息数据集（各省 xlsx） |
| 来源链接 | <https://github.com/xjtulyc/Electric_Vehicle_Crawler>（`crawler/充电桩/` 目录） |
| 原始规模 | 33 个省级文件，34,186 条站点记录 |
| 采集口径 | 站点名称、地址、快充/慢充数量、支付方式、充电费、服务费、停车费、开放时间 |
| 使用方式 | 下载后放在项目 `data_raw/` 目录，由 `database/clean_dataset.py` 清洗入库 |

原始字段到入库字段的对应关系：

| 原始字段 | 入库字段 | 处理方式 |
| --- | --- | --- |
| 名称 | station_name | 去首尾空格 |
| 地址 | province / city / address | 按省文件名确定省份，从地址正则解析城市；解析不到记为“未知” |
| 快充数量 | fast_piles | 转整数，缺失按 0 处理 |
| 慢充数量 | slow_piles | 转整数，缺失按 0 处理 |
| 充电费 | electricity_price | 解析分时段价格取平均（5 种原始写法） |
| 服务费 | service_price | 同上 |
| 充电费 + 服务费 | total_price | 两者相加 |
| 停车费 | parking_free | 文本含“免费”记 1，否则 0 |
| 开放时间 | open_24h | 含“00:00-24:00”记 1，否则 0 |
| 快充 + 慢充 | total_piles / scale_level | 相加后按 1-5、6-10、11-20、20 以上分档 |

## 二、清洗策略

清洗脚本 `database/clean_dataset.py` 按以下顺序处理，每一步的删除/填充条数都会写入 `docs/cleaning_report.json`：

1. **去重**：以“站点名称 + 地址”为唯一键，删除 63 条重复记录。
2. **无效记录剔除**：快充与慢充数量都为 0 的记录无法参与统计，删除；单项超过 500 个视为录入异常，删除。共 471 条。
3. **异常价格处理**：充电电费小于等于 0 或大于 3 元/度不符合实际，置为空值（889 条）；服务费同理。
4. **缺失值填充**：价格字段按“同省中位数”填充（电费 1,798 条、服务费 7,173 条），避免直接删除造成样本偏差；仍无法填充时用全表中位数兜底。
5. **城市缺失处理**：地址里没有市名的记录不删除，城市记为“未知”，在城市排行中排除（4,981 条）。

清洗结果：33,652 条入库记录，31 个省级行政区、633 个城市，快充桩 309,180 个、慢充桩 36,440 个。

## 三、系统结构

- **数据层**：SQLite，单表 `charging_stations`，建 `province`、`city`、`scale_level` 三个索引。
- **服务层**：Flask 提供 7 个接口，全部用 SQL 聚合，省份过滤统一用 `?` 占位符，避免拼接注入。
- **展示层**：单页 ECharts 大屏，按 1920×1080 固定画布设计，打开时按窗口比例整体缩放，保证一屏完整展示。

## 四、图表与聚合逻辑

| 图表 | 接口 | 聚合 SQL |
| --- | --- | --- |
| 顶部 6 个指标卡 | `/api/kpi` | `COUNT(*)`、`SUM(fast_piles)`、`SUM(slow_piles)`、`COUNT(DISTINCT city)`、`AVG(electricity_price)`、`AVG(service_price)` |
| 全国各省充电站数量地图 | `/api/map-data` | `GROUP BY province`，输出站点数、快慢充桩数、平均电费 |
| 站点规模分布环形图 | `/api/scale-dist` | 按 `scale_level` 分组，`COUNT(*)` 与 `SUM(total_piles)` |
| 快充/慢充结构玫瑰图 | `/api/pile-structure` | `SUM(fast_piles)`、`SUM(slow_piles)` |
| 城市充电站数量 TOP10 | `/api/city-top` | `GROUP BY city` + `ORDER BY COUNT(*) DESC LIMIT 10`，排除“未知” |
| 电费区间分布 | `/api/price-dist` | `CASE WHEN` 分段 + `GROUP BY`，分 5 档统计站点数 |
| 底部站点明细 | `/api/station-feed` | 随机取 6 条，用于展示明细字段 |

## 五、联动设计

- 地图省份点击 → `setFilterProvince(省份名)`，把省份写入全局状态。
- 该函数依次重新请求 5 个接口，并将结果通过 `setOption(option, true)` 覆盖渲染。
- 顶部显示当前下钻域，出现“重置下钻”按钮，点击恢复全国视图。
- 也支持直接通过 `/?province=广东省` 打开下钻视图，便于演示和自动截图。
