## 每日记录

### 2026-10-10 ｜ 选题与技术方案
- **今日进展**：通读题库，选题目六（数据可视化大屏）；确定用 Flask + SQLite + ECharts，先做单页大屏，不做登录。
- **遇到问题**：一开始想用 MySQL，考虑到评阅机不一定装数据库，改成 SQLite 单文件，随仓库一起提交。
- **产出**：选题说明、技术方案草稿、工程目录规划。
- **里程碑**：M0 ✅

### 2026-10-15 ｜ 工程骨架与页面布局
- **今日进展**：建 `app/`、`database/`、`docs/`、`screenshots/`；写 `index.html` 和 `screen.css`，定下深色底、三栏布局、顶部 6 个指标卡、底部明细表。
- **遇到问题**：图表容器高度不够，地图和左右两侧对不齐，调了两轮 grid 比例才顺眼（26% / 46% / 28%）。
- **产出**：页面骨架、样式文件、ECharts 本地库。
- **里程碑**：M1 ✅

### 2026-10-20 ｜ 后端接口
- **今日进展**：写 `server.py`，实现指标卡、地图、城市、规模、快慢充、电费区间 6 个聚合接口，加 1 个明细抽样接口；省份过滤统一用占位符传参。
- **遇到问题**：`/api/kpi` 里的子查询也要用同一个条件，参数得传两遍，一开始只传了一遍，带省份请求会报参数数量不匹配（见 DEBUG-005）。
- **产出**：`app/server.py`、`database/schema.sql`。
- **里程碑**：M2 ✅

### 2026-10-25 ｜ 前端图表与联动
- **今日进展**：完成 5 个图表配置、地图点击下钻、重置按钮、8 秒刷新明细列表；把 ECharts 和中国地图 GeoJSON 都下到本地，不依赖 CDN。
- **遇到问题**：地图点完省份，其他图更新了但地图自己不高亮；另外重复调用 `echarts.init` 会有实例告警，改成统一用 `getChart()` 复用。
- **产出**：`screen_engine.js`、地图与图表配置。
- **里程碑**：M3 ✅

### 2026-10-29 ｜ 数据源整改与整体重构
- **今日进展**：
  1. 原来用的是脚本随机生成的数据，不符合题目“公开数据集 + 注明来源”的要求，换成 GitHub 公开仓库里的全国充电站数据（33 个省级 xlsx，34,186 条）。
  2. 写 `database/clean_dataset.py`：解析地址、解析 5 种价格写法、去重、剔除无效与异常记录、按省中位数补缺失，最终入库 33,652 条。
  3. 后端接口、前端指标和 5 个图表全部按新数据重写（站点数、快充桩、慢充桩、城市 TOP10、电费区间）。
  4. 页面改成 1920×1080 固定画布 + 整体缩放，解决之前一屏放不下、要滚动的问题。
- **遇到问题**：价格文本有 5 种格式，第一版正则只覆盖其中一种，80% 解析不出来（见 DEBUG-003）；地图数据字段名用成了 `province`，ECharts 要 `name`，导致全国地图不上色（见 DEBUG-001）；带 `?province=` 打开时联动数据被初始请求覆盖（见 DEBUG-002）。
- **产出**：新的 `analytics.db`、清洗统计 `cleaning_report.json`、新截图、更新后的 README 与报告。
- **里程碑**：M4 ✅、M5 ✅
